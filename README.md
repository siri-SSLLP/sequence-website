## 🔄 Git Workflow (GitFlow)

We follow a structured **GitFlow strategy**:

### 🌿 Main Branches

- `main` → Production-ready code
- `develop` → Active development branch

---

### 🌱 Supporting Branches

#### ✨ Feature Branches
- Naming: `feature/<feature-name>`
- Created from: `develop`
- Example: feature/product-page

#### 🐞 Bugfix Branches
- Naming: `bugfix/<issue-name>`
- Created from: `develop`

#### 🚀 Release Branches
- Naming: `release/<version>`
- Used for final testing before production

#### 🔥 Hotfix Branches
- Naming: `hotfix/<issue-name>`
- Created from: `main`
- Used for urgent production fixes

---

### 🔁 Workflow Steps

1. Create branch from `develop`
2. Work on feature/bugfix
3. Commit with proper messages: git commit -m "Add product card component"
4. Push branch: git push origin feature/product-page

5. Create Pull Request → `develop`
6. Code Review & Approval
7. Merge into `develop`
